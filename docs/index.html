🤖 マイクロビット 体験ワークショップ

🔰 基礎編 マイクロビットを使いこなそう
1🔰

マイクロビットの紹介と使い方

マイクロビットって何？ はじめてのプログラムを書きこもう。
2🎬

アニメーションをつくろう

LEDで少しずつ違う絵を順番に表示して、アニメーションを作ろう。
3🔘

ボタンで表示を変えよう

A・Bボタンを使って、LEDの表示や動きを変えてみよう。
4🔔

揺らして音を鳴らそう

スピーカーと加速度センサーを使って、揺らすと音が鳴るようにしよう。
5☀️
🚧 工事中

明るさをはかろう

光センサーでまわりの明るさをはかって、暗くなったら自動で光るライトを作ろう。
6🎤
🚧 工事中

音に反応させよう

マイクで音の大きさをはかって、手をたたくと表示が変わるようにしよう。
7📡

無線で通信しよう

2台以上のマイクロビットで、電波を使ってメッセージを送り合おう。
🧩 応用編 変数・くりかえし・条件分岐でプログラムの力をつけよう
1🔢
🚧 工事中

変数を使おう

数字を入れておく「変数」を使って、ボタンで数が増えたり減ったりするカウンターを作ろう。
2🎯
🚧 工事中

条件分岐を使おう

カウンターの数を点の場所にして、ボタンでLEDの点を動かそう。「もし〜なら」で端の動きを決めよう。
3🔁
🚧 工事中

くりかえしを使おう

「くりかえし」ブロックで、LEDの点を左から右に流そう。少ないブロックでアニメーションが作れるよ。
🔌 拡張編 外部デバイスをつないで広げよう
1🌈

フルカラーLEDを使おう

NeoPixel を接続して、いろいろな色やレインボーを光らせよう。作品づくりにも挑戦。
2🦾

サーボモーターを動かそう

サーボモーターをつないで、角度を指定して動かしてみよう。
3🚶
🚧 工事中

人感センサーを使ってみよう

人が動いたのを検知して、LED表示を変えたり音を鳴らしたりしよう。
🚗 ロボットカー編（micro:Maqueen）
1🚗
入門編

基本走行

ロボットカーを組み立てて、前後・右折・左折。三角形や円を描いて自由に走らせよう。
2🎤
中級編

センサーで動かそう

マイク（拍手）で操縦したり、超音波センサーでぶつかる前に自動で曲がろう。
3🛣️
上級編

ライントレーサー

床の線をセンサーで見分けて、自動で線をたどって走るロボットを作ろう。
💻 コーディング編 ブロックから文字のプログラム（JavaScript / Python）へ
1💻

JavaScript を使ってみよう

ブロックを「文字のプログラム」に切りかえて、コードを読んで・コピーして・書きかえてみよう。
2🐍

Python を使ってみよう

同じブロックを Python に切りかえてみよう。字下げでプログラムの形を作るのがコツだよ。
