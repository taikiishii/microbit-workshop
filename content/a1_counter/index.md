# 🔢 変数を使おう

カウンターを作ろう

---

# なにをするの？

:::

プログラムで数字をおぼえておきたいときは、**変数（へんすう）** を使うよ。

変数は、数字を入れておく **箱** のようなもの。箱に **名前** をつけて、中身をあとから **増やしたり減らしたり** できるんだ。

今回は「**Aボタンで 1 増える、Bボタンで 1 減る**」カウンターを作ってみよう！

> 応用編では、この数を使って **LEDの点を動かしたり**、**くりかえし** で光らせたりしていくよ。

:::

📷 ここに図か写真：「count」と名前のついた箱に数字が入っているイメージ、またはマイクロビットに数字が出ている写真

---

# ① 変数を作ろう

:::

1. 「**変数**」のメニューをクリックし、「**変数を追加...**」を押す
2. 名前を `count` と入力して「**OK**」
3. メニューに「**count**」「**変数 count を 0 にする**」「**変数 count を 1 だけ増やす**」の3つのブロックがふえる

> 名前は英語で `count`（カウント＝数える）にしよう。自分で決めた名前が、そのままブロックになるんだ。

:::

📷 ここにメイクコードの画面：「変数を追加...」のダイアログと、ふえた3つのブロック

---

# ② ボタンで数を増やそう

:::

1. 「**変数 count を 0 にする**」を「**最初だけ**」の中に入れる
2. 「**入力**」から「**ボタンAが押されたとき**」を置く
3. 「**変数 count を 1 だけ増やす**」を、その中に入れる
4. 「**基本**」の「**数を表示**」を下につなげて、数字のところに「**count**」を入れる
5. 「**ダウンロード**」で書きこんで、Aボタンを押してみよう

> 押すたびに 1、2、3… と増えていくよ。「最初だけ」で 0 にしておくのは、スタートの数を決めるためだよ。

:::

📷 ここにメイクコードの画面：「最初だけ：変数 count を 0 にする」と「ボタンAが押されたとき：変数 count を 1 だけ増やす、数を表示 count」

---

# ③ Bボタンで減らそう

:::

1. 「ボタンAが押されたとき」を右クリックして「**複製する**」
2. 「**A**」を「**B**」に変える
3. 「1 だけ増やす」の `1` を `-1` にする

> マイナスの数だけ「増やす」と、減るんだね。0 より小さくすると **マイナス** の数も出てくるよ。

:::

📷 ここにメイクコードの画面：Bボタンのブロック（変数 count を -1 だけ増やす、数を表示 count）

---

# ためしてみよう

:::

- **Aボタン** を押すと… 1 増える
- **Bボタン** を押すと… 1 減る

> 数字が出るまで少し時間がかかるよ。連打しないで、ゆっくり押してね。

> 💪 「**A+B**」を押したら 0 にもどるようにしてみよう。「変数 count を 0 にする」を使うよ。

> 💪 「ゆさぶられたとき」に 0 にもどす、10 ずつ増やす、など自分だけのカウンターにしてみよう。

:::
