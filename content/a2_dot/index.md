# 🎯 条件分岐を使おう

点を動かそう

---

# なにをするの？

:::

「変数を使おう」で作ったカウンターの数を、こんどは **LEDの点の場所** に使うよ。

LED画面の場所は、**横が x**、**たてが y** の数字で決まっているんだ。どちらも **0〜4** だよ。

- Aボタンで x が 1 増えて、点が **右** に動く
- Bボタンで x が 1 減って、点が **左** に動く

そして、端まで行ったらどうするかを「**もし〜なら**」で決めるよ。

> 「明るさをはかろう」で使った「もし〜なら」を、もう一度使うよ。

:::

📷 ここに図：5×5 のマス目に x=0〜4（横）と y=0〜4（たて）の数字を書いたもの。左上が (0, 0)

---

# ① 点を表示しよう

:::

「変数を使おう」のプログラムをひらいて、つづきから作るよ。

1. Aボタンの中の「**数を表示**」を外して消す
2. かわりに「**基本**」の「**表示を消す**」と、「**LED**」の「**点灯 x: 0 y: 0**」を入れる
3. 「点灯」の x のところに「**変数**」の「**count**」を入れて、y を `2` にする
4. Bボタンも同じようにする
5. 「**最初だけ**」にも「**点灯 x: count y: 2**」を足しておく

> 「表示を消す」を先にやるのは、前の場所の点を消してから、新しい場所に点けるためだよ。

> 「最初だけ」の `0` を `2` にすると、点がまん中からスタートするよ。

:::

📷 ここにメイクコードの画面：「ボタンAが押されたとき：変数 count を 1 だけ増やす、表示を消す、点灯 x: count y: 2」と、同じ形のBボタン

---

# ② 端まで動かすと…？

:::

「**ダウンロード**」で書きこんで、Aボタンを押してみよう。

- 点が右に動く。右端（x = 4）まで行ったら、**もう1回** 押してみよう
- 点が **消えてしまう**！

> x が 5 になると、LED画面の外なので何も表示されないんだ。count はそのまま増えつづけているよ。

こんなときは「**もし** 5 になったら **0 にもどす**」というルールを足せば、点が反対側からワープして出てくるよ。

:::

📷 ここに写真：右端で点が消えてしまったマイクロビット、または図

---

# ③ 「もし」で端のルールを決めよう

:::

1. 「**論理**」から「**もし〜なら**」を、Aボタンの「1 だけ増やす」の**すぐ下**に入れる
2. 「**論理**」の「**くらべる**」から「**0 ＜ 0**」を条件に入れ、▼で「**＞**」にする。左に「**count**」、右に `4`
3. 「もし」の中に「**変数 count を 0 にする**」を入れる
4. Bボタンにも同じように「**もし count ＜ 0 なら count を 4 にする**」を入れる

> 「もし〜なら」は、**条件が正しいときだけ** 中のブロックを動かすよ。ちがうときは何もしないで通りすぎるんだ。

> ⚠ 「表示を消す」「点灯」よりも **前** に入れよう。順番が大事だよ。

:::

📷 ここにメイクコードの画面：Aボタン：変数 count を 1 だけ増やす、もし count ＞ 4 なら 変数 count を 0 にする、表示を消す、点灯 x: count y: 2

---

# ためしてみよう

:::

- **右端でAボタン** … 左端にワープ
- **左端でBボタン** … 右端にワープ

> 💪 ワープじゃなくて **端で止まる** ようにするには？ 「count を 0 にする」のかわりに「count を 4 にする」にしてみよう。

> 💪 変数 `y` を作って、**タッチロゴ** や「**かたむけた**」で上下にも動かしてみよう。

> 💪 「ゆさぶられたとき」で **まん中にもどる** ようにしてみよう。

:::

📷 ここに写真：点が動いているマイクロビット
