# 📟 LEDマトリクスで電光掲示板を作ろう

文字を流して、点を動かそう（MAX7219）

---

# なにをするの？

:::

**LEDマトリクス** は、LEDを **たて8個 × よこ8個** にならべた部品だよ。今回使うのは、それが **4枚** つながった横長のタイプなんだ。

- LEDの数は **8 × 8 × 4 ＝ 256個**（マイクロビットの画面は25個）
- 駅やお店の **電光掲示板** のように、文字を流せる
- 1つ1つの点を光らせて、絵もかける

> **MAX7219** は、LEDマトリクスを光らせるための小さなコンピュータの名前だよ。1枚に1つずつ入っているんだ。

:::

📷 ここに LEDマトリクスの写真：4枚がつながった横長のモジュールを表から。左はしに5本のピン（VCC・GND・DIN・CS・CLK）が見えるように

---

# LEDマトリクスをつなごう

:::

ワニ口クリップで **5本** つなぐよ。ピンの名前を見ながら、1本ずつつなごう。

- **VCC** → マイクロビットの **3V**
- **GND** → **GND**
- **DIN** → 端子 **2**
- **CS** → 端子 **1**
- **CLK** → 端子 **0**

> ピンが5本ならんでいる側につなごう。反対側にもピンがあるけど、そちらは使わないよ。

> ⚠ ワニ口クリップどうしが **さわらない** ように気をつけよう。わからないときはメンターと一緒に確かめよう。

:::

📷 ここに つないだ写真：マイクロビットの 0・1・2・3V・GND と、LEDマトリクスの CLK・CS・DIN・VCC・GND がワニ口クリップでつながっているところ

---

# 拡張機能を追加しよう

:::

LEDマトリクスを使うには、**MAX7219** という拡張機能を追加するよ。

1. 「**拡張機能**」をクリック
2. `MAX7219` と入力してさがす
3. 出てきたカードをクリック
4. メニューに「**MAX7219 8x8**」がふえる

> この拡張機能のブロックは **英語** で書いてあるよ。この章では、ブロックの名前を英語のまま書くね。

:::

📷 ここにメイクコードの画面：拡張機能の検索で「MAX7219」と入れて、カードが出ているところ

---

# はじめの準備をしよう

:::

つないだ端子と、マトリクスの枚数をおしえるよ。

1. 「**MAX7219 8x8**」の「**Setup MAX7219**」を「**最初だけ**」に入れる
2. **Number of matrixs** を `4` にする
3. 端子を **CS＝P1**・**MOSI＝P2**・**MISO＝P3**・**SCK＝P0** にする
4. 「**Set all brightness level**」を下に入れて、`7` にする

> MISO は使わないので、P3 には何もつながなくていいよ。

:::

📷 ここにメイクコードの画面：「最初だけ」に Setup MAX7219（4・P1・P2・P3・P0）と Set all brightness level 7 が入っているところ

---

# 表示の向きを合わせよう

:::

このLEDマトリクスは、そのままだと文字が **さかさま** に出るよ。向きを回す設定を足そう。

1. 「**MAX7219 8x8**」の「**その他**」をひらく
2. 「**Rotate matrix display**」を、「Set all brightness level」の下に入れる
3. 向きを **180-degree**（180度）にする

> もし文字がさかさまのままなら、向きを **none** にしてためそう。

:::

📷 ここにメイクコードの画面：「最初だけ」の Set all brightness level 7 の下に Rotate matrix display 180-degree／Reverse printing order 偽 が入っているところ

---

# 文字を流そう

:::

1. 「**Scroll text**」を「**ずっと**」に入れて、文字を `Hello!` にする
2. 書きこんで、右から左へ文字が流れたら大成功！ 🎉

- **delay (ms)** … 1列ずらすごとに待つ時間。小さいほど **速い**
- **at the end wait (ms)** … 流れ終わってから待つ時間

> ⚠ 出せるのは **英語の文字・数字・記号** だけ。ひらがなや漢字は出ないよ。

> シミュレータにはLEDマトリクスが出ないよ。実物で見てね。

:::

📷 ここにメイクコードの画面：「ずっと」に Scroll text "Hello!" delay 75 at the end wait 500 が入っているところ

---

# 文字を止めて表示しよう

:::

流さずに、パッと表示もできるよ。

1. 「**ずっと**」の「**Scroll text**」をはずす
2. 「**ボタンAが押されたとき**」に「**Display text (align left)**」を入れて、`Hi!` にする
3. 「**ボタンBが押されたとき**」に「**Display text (align right)**」を入れて、`OK` にする

> **align left** は左にそろえる、**align right** は右にそろえる、という意味だよ。

> 💪 align left の **offset** を `0`→`8`→`16` と変えると、どうなるかな？

:::

📷 ここにメイクコードの画面：ボタンA に Display text (align left) "Hi!"、ボタンB に Display text (align right) "OK" が入っているところ

# 温度計を作ろう

:::

マイクロビットの **温度センサー** の数字を表示してみよう。

1. 「**ずっと**」に「**Display text (align right)**」を入れる
2. 文字のところに、「**入力**」の「**温度（℃）**」を入れる
3. 「**基本**」の「**一時停止（ミリ秒）**」を下に入れて、`1000` にする

> 💪 マイクロビットを手でにぎると、温度が上がるよ。何度まで上がるかな？

:::

📷 ここにメイクコードの画面：「ずっと」に Display text (align right) と「温度（℃）」、一時停止 1000 が入っているところ

# 点をかく紙を用意しよう

:::

こんどは、点を1つずつ光らせるよ。まず、点をかくための **まっ白な紙** を用意するんだ。

1. 「**ずっと**」の中を空にする
2. 「**変数**」で、変数 `pattern`（パターン＝もよう）を作る
3. 「**ずっと**」に「**変数 pattern を 0 にする**」を入れる
4. 0 のところに「**Empty 8x8 pattern**」を入れる

> **Empty 8x8 pattern** は、ぜんぶ消えている 8x8 のもようだよ。

:::

📷 ここにメイクコードの画面：「ずっと」に 変数 pattern を Empty 8x8 pattern にする が入っているところ

# 点を1つ光らせよう

:::

点の場所は、**x（よこ）** と **y（たて）** の数字で決めるよ。どちらも **0〜7** だよ。

1. 「**Set 8x8 pattern**」を下に入れて、もようのところに「**pattern**」、x と y を `0`、value を `1` にする
2. 「**Display 8x8 pattern**」を下に入れて、もようのところに「**pattern**」、index を `3` にする

> 💪 x: 0 y: 0 の点はどこに光ったかな？ **index** を `0`〜`3` に変えると、どのマトリクスに出るか調べよう。

:::

📷 ここにメイクコードの画面：「ずっと」に 変数 pattern を Empty 8x8 pattern にする／Set 8x8 pattern pattern x 0 y 0 value 1／Display 8x8 pattern pattern on matrix index 3 が入っているところ

---

# くりかえしで線をかこう

:::

「くりかえし」を使うと、たくさんの点をまとめてかけるよ。

1. 「**ループ**」の「**変数 カウンター を 0〜4 に変えてくりかえす**」を、「Set 8x8 pattern」の **まわり** に入れる
2. `4` を `7` にする
3. 「Set 8x8 pattern」の x と y の **両方** に「**カウンター**」を入れる

カウンターが 0、1、2 … 7 と変わって、**ななめの線** がかけるよ。

> 💪 y を `3` にしたら、どんな線になるかな？

:::

📷 ここにメイクコードの画面：「変数 カウンター を 0〜7 に変えてくりかえす」の中に Set 8x8 pattern pattern x カウンター y カウンター value 1 が入っていて、その下に Display 8x8 pattern がつながっているところ

---

# ボタンで点を動かそう

:::

「条件分岐を使おう」と同じように動かすよ。

1. 変数 `x` を作り、「**最初だけ**」の下に「**変数 x を 0 にする**」を入れる
2. 「くりかえし」をはずして、「Set 8x8 pattern」の x に「**x**」、y に `3` を入れる
3. 「**ボタンAが押されたとき**」に「**変数 x を 1 だけ増やす**」と「**もし x ＞ 7 なら x を 0 にする**」を入れる
4. 「**ボタンBが押されたとき**」に「**変数 x を -1 だけ増やす**」と「**もし x ＜ 0 なら x を 7 にする**」を入れる

> ⚠ x が 8 になるとマトリクスの外なのでエラーになるよ。「もし」を忘れずに。

:::

📷 ここにメイクコードの画面：ボタンA・ボタンB のプログラムと、「ずっと」の Set 8x8 pattern pattern x x y 3 value 1

# もっとやってみよう

> 💪 自分の **名前** をローマ字で流そう。ボタンでメッセージを切りかえてもいいね。

> 💪 「**Set all brightness level**」の数（0〜15）を変えて、明るさを変えよう。

> 💪 「**Randomize all LEDs**」と「一時停止」を「ずっと」に入れると、どんなふうに光るかな？

> 💪 「**入力**」の「**明るさ**」や「**音の大きさ**」も、温度と同じように表示できるよ。
